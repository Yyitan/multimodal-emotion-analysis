# 多模态情感分析：方法与代码实现总结

## 1. 完成状态

本工程基于 CMU-MOSEI 公开数据集，完成三大功能模块的端到端实现、真实运行和结果校验：

1. **模块一（特征提取与对齐）**：100条原始视频的文本、语音、视觉特征提取及时序对齐；
2. **模块二（鲁棒预测）**：局部模态缺失条件下的三分类与连续情感强度鲁棒预测；
3. **模块三（可解释性）**：模态贡献、局部证据和原视频时间定位的可解释预测。

所有训练、验证和统计仅使用 CMU-MOSEI 系列公开数据。模态缺失评测集和可解释性评测集为无标签评测集，只做最终推理；未利用它们与对齐特征集的重合样本反查标签。

## 2. 模块一：三模态特征提取与时序对齐

### 2.1 处理流程

对原始视频集的100条视频执行：

1. 根据 `label-100.xlsx` 建立 `video_id + clip_id` 唯一样本清单；
2. 用 FFprobe 记录时长、帧率、分辨率、音轨等信息；
3. 用 FFmpeg 提取16 kHz单声道PCM音频；
4. 用固定版本 `bert-base-uncased` 生成最多50个位置的768维文本表示；
5. 使用 `wav2vec2-base-960h` 对数据集提供的英文转写和音频进行CTC强制对齐；
6. 在每个文本时间窗内聚合74维语音特征和35维视觉特征；
7. 输出统一长度50的特征、掩码、起止时间、token/word和异常标记。

### 2.2 特征定义

语音每帧严格为74维：

- 20维 MFCC；
- 20维一阶差分；
- 20维二阶差分；
- 12维 Chroma；
- 1维 RMS；
- 1维基频 F0。

视觉采用官方 MediaPipe `face_landmarker_v2_with_blendshapes.task`，模型 SHA-256 为：

```text
41502960a7323080e5bbf46804f4fe6d0d83aa0aa82ba3209831286e94300083
```

模型实际输出52个 blendshape 类别，代码固定选择35项作为可复现的面部行为表示。该35维特征是本项目自定义、可解释的替代表示，**不声称与对齐特征集原始35维视觉特征完全同源**。

每条样本输出：

```text
text    : (50, 768)
audio   : (50, 74)
vision  : (50, 35)
```

以及 `text_mask`、`audio_mask`、`vision_mask`、视觉检测掩码、位置起止时间和异常字段。

## 3. 模块二：局部模态缺失下的鲁棒情感预测

### 3.1 数据接口处理

主路线使用对齐特征集 `aligned_50.pkl`。文本、语音、视觉长度均为50，便于显式定位局部缺失。

数据层做了以下关键处理：

- 文本有效位置严格使用 `text_bert` 的 attention mask，不能根据768维文本向量是否为零判断；
- 音频和视觉在文本有效轴内再判断非零和有限值；
- 不使用存在大量不一致的 `vision_lengths` 直接裁剪；
- 模态缺失评测集的 `text_bert` 虽保存为 `float32`，但已逐个确认是有限整数，再安全转换为 `int64`；
- 模态缺失评测集没有预计算 `text`，代码通过相同 `bert-base-uncased` 最后一层重建。与对齐特征集现成 `text` 的核验误差为：MAE约 `4.85e-7`、最大误差约 `9.06e-6`，因此训练和评测集推理的文本分布一致。

### 3.2 模型

实现的是轻量级掩码感知动态门控多任务模型：

1. 三个模态分别投影到共同隐藏空间；
2. 模态编码器提取时序表示；
3. 每个时间位置根据内容和可用性掩码计算动态门控权重；
4. 缺失位置被严格屏蔽，其余模态权重重新归一化；
5. 融合表示同时进入三分类头和回归头；
6. 回归输出限制在 `[-3,3]`。

训练时在线生成文本、语音、视觉及其组合的连续缺失区间，并同时使用完整视图和缺失视图。损失由分类交叉熵、回归损失以及完整/缺失视图的一致性损失组成。

冻结模型仅约8.0万参数，checkpoint约0.34 MB；公共BERT权重不打入checkpoint。

### 3.3 模型选择

模型和随机种子只使用对齐特征集验证集选择。固定联合准则为：

```text
0.35 × Macro-F1
+ 0.15 × Accuracy
+ 0.25 × ((Pearson + 1) / 2)
+ 0.25 × (1 - clip(MAE, 0, 6) / 6)
```

三个随机种子的验证结果：

| Seed | Accuracy | Macro-F1 | MAE | Pearson | 联合分数 |
|---:|---:|---:|---:|---:|---:|
| 2026 | 0.6209 | 0.6094 | 0.5857 | 0.6614 | **0.7397** |
| 3407 | 0.6319 | 0.6014 | 0.5890 | 0.6512 | 0.7371 |
| 20260923 | 0.6250 | 0.5908 | 0.5865 | 0.6474 | 0.7320 |

因此冻结 seed 2026、epoch 2 的模型。没有根据对齐特征集测试集或模态缺失评测集选择模型。

### 3.4 基础性能

| 数据划分 | Accuracy | Macro-F1 | Weighted-F1 | MAE | Pearson |
|---|---:|---:|---:|---:|---:|
| valid | 0.6209 | 0.6094 | 0.6246 | 0.5857 | 0.6614 |
| test | 0.6465 | 0.6111 | 0.6513 | 0.6438 | 0.6690 |

与简单拼接基线相比，冻结模型在验证集上的 Accuracy 略低0.0027，但 Macro-F1提高0.0091、MAE降低0.0293、Pearson提高0.0228。说明改进主要体现在类别均衡性和强度回归，而不是单一准确率。

完整输入下，无缺失增强/无一致性损失两个消融的部分指标高于主模型，因此**不能把完整输入消融包装为全面收益**。缺失增强和一致性训练的价值应以局部缺失压力测试为主，而不是只看clean输入。

### 3.5 缺失压力测试

验证集正式评估281个条件，测试集按冻结后的预注册网格评估36个条件。每个条件使用2000次按 `video_id` 分组的bootstrap计算95%置信区间。

覆盖：

- 模态：T、A、V、TA、TV、AV、TAV；
- 缺失率：0、0.1、0.2、0.3、0.5、0.7；
- 位置：head、middle、tail、random；
- 单段及多段连续缺失。

真实规律：

- 模型对**文本缺失最敏感**；
- 单独语音缺失影响很小，说明当前冻结模型对音频依赖偏弱；
- 50%随机单段缺失时，TA组合的Macro-F1较clean下降约0.0111；单独文本下降约0.0089；单独语音几乎不变；
- 最坏验证条件是文本与语音尾部同时缺失70%，Macro-F1为0.5602，Accuracy为0.5687；
- 单模态50%缺失时，头部缺失平均影响大于中部、随机和尾部缺失。

完整矩阵和图表位于：

- `artifacts/metrics/robustness_valid.csv`
- `artifacts/metrics/robustness_test.csv`
- `artifacts/figures/`

## 4. 模块三：可解释情感预测

### 4.1 解释方法

模块三复用模块二的冻结主干，不在可解释性评测集上调参。

模态级解释采用三模态精确Shapley。只有T/A/V三种模态，因此穷举全部 `2^3=8` 个模态联盟即可得到无采样误差的Shapley值。输出：

- 三模态有符号贡献；
- 绝对值L1归一化后的作用程度；
- 主要参考模态；
- 并列或弱信号标记。

局部解释采用滑动窗口遮挡：遮掉某个模态的局部连续位置，比较预测类别概率或回归值变化。相邻高重要性窗口合并为证据区间。

解释忠实性使用：

- Top证据累计删除AOPC；
- 固定种子随机删除对照；
- 删除主要模态与次要模态的输出下降；
- 解释稀疏性；
- 轻微扰动下Shapley余弦、主要模态不变率和证据Jaccard。

### 4.2 验证集解释质量

对齐特征集 valid共728条，分类和回归共1456条解释记录。

| 指标 | 分类解释 | 回归解释 |
|---|---:|---:|
| Top证据删除AOPC | 0.04766 | 0.09239 |
| 随机删除AOPC | 0.00318 | 0.00304 |
| AOPC增益 | 0.04448 | 0.08935 |
| 主要模态删除drop | 0.25113 | 0.39736 |
| 次要模态删除drop | -0.02076 | 0.02628 |
| Shapley余弦稳定性 | 0.999986 | 0.999993 |
| 主要模态不变率 | 100.00% | 99.73% |
| Top证据Jaccard | 0.9873 | 0.9828 |

分类解释中，Top证据删除优于随机删除的比例为98.90%；回归解释中为99.73%。

需要如实注意：回归任务中“删除主要模态造成的下降大于删除次要模态”的比例为63.05%，说明回归解释并非每条样本都呈现非常清晰的主次模态分离。

## 7. 当前限制与建议改进方向

代码已经解决三个问题，但仍有可继续改进之处：

1. **音频利用不足**：局部音频缺失对结果几乎无影响，表明门控网络可能过度依赖文本。可尝试模态均衡正则、门控熵约束、音频辅助任务或对比学习。
2. **无人脸样本**：特征提取阶段有13条视频未检测到人脸。可增加检测器回退、人脸跟踪、低分辨率增强或手部/姿态特征。
3. **近似对齐**：12条文本包含CTC词表不支持字符或置信度较低。可增加规范化规则，或使用词表更完整的英文强制对齐模型。
4. **完整输入消融**：无缺失增强/无一致性损失在clean验证集上的部分指标更高，说明鲁棒训练存在clean性能和缺失性能的权衡。后续应以Pareto方式选择一致性权重，而不是只优化单一场景。
5. **回归解释主次分离**：仅63.05%的验证样本满足“删除主要模态比次要模态影响更大”。可尝试条件Shapley、交互Shapley或基于反事实优化的局部解释。
6. **未对齐版本**：当前正式主路线使用aligned_50。后续可加入unaligned版跨模态注意力作为扩展，但必须重新处理模态缺失评测集缺少文本数值特征和有效长度的问题。
7. **评测集无真值**：模态缺失评测集/4没有官方标签，因此评测集结果不能报告Accuracy或MAE；当前只提供预测、模型内质量指标和验证集证据。

以上限制均未被掩盖，相关异常和回退规则都保存在审计文件与逐样本元数据中。
