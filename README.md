# 多模态情感分析与可解释预测

本仓库是一个完整的多模态情感分析项目，覆盖从原始视频到可解释预测结果的端到端流程：文本/语音/视觉特征提取与词级时序对齐、局部模态缺失下的鲁棒情感预测、以及基于精确 Shapley 与局部证据的可解释性分析。仓库包含可运行代码、配置、测试、轻量冻结模型、实验指标、预测结果和解释结果。**仓库不包含原始数据或逐样本NPZ特征。**

## 三大功能模块

- 模块一（特征提取与对齐）：文本/语音/视觉特征提取与词级时序对齐；
- 模块二（鲁棒预测）：局部模态缺失下的三分类与情感强度鲁棒预测；
- 模块三（可解释性）：精确三模态Shapley、局部证据、AOPC忠实性评估和原视频时间定位。

详细方法与真实结果见 [`docs/技术总结.md`](docs/技术总结.md)。

## 环境

推荐 Python 3.10。先创建独立环境，再安装：

```bash
pip install -r requirements-direct.txt
```

特征提取模块还需要 `ffmpeg`/`ffprobe`，并按配置下载固定版本的 BERT、Wav2Vec2 和 MediaPipe Face Landmarker 公共模型。
